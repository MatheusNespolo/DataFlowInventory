# Comentários e modelos de cards (arquivo)

> **Esta pasta é um arquivo.** A fonte do andamento de cada frente é o [GitHub Project](https://github.com/users/MatheusNespolo/projects/3): os cards são as issues, e o registro de cada rodada vai como **comentário na própria issue**. Não crie aqui cópias de comentários que já estão (ou vão estar) no GitHub — duas cópias sempre divergem.

Os arquivos ficam por histórico e porque algumas issues apontam para eles:

| Arquivo | O que é |
|---|---|
| `card_*.md` | Corpo original (Template A) de cards criados em setembro; a issue correspondente aponta para ele |
| `comentarios_semana_*.md` | Textos de comentários preparados para atualizações do board (semanas 7 e 10) |
| [`sugestoes_cards_setembro_2026.md`](sugestoes_cards_setembro_2026.md) | Rascunhos de comentários que ficavam no plano de testes |
| [`catalogo_cards_setembro_2026.md`](catalogo_cards_setembro_2026.md) | Catálogo de cards que ficava no guia do board |

Modelos de comentário e regras do board: [`docs/fluxogramas/board_github_projects.md`](../fluxogramas/board_github_projects.md).
